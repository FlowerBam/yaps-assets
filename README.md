# yaps-assets

yaps.tistory.com 블로그용 이미지 CDN 저장소. jsDelivr로 서빙됨.

**파일명 변경 금지 (글 HTML에서 직접 참조 중).**

## 사용법

```
https://cdn.jsdelivr.net/gh/FlowerBam/yaps-assets@main/emo/<파일명>.webp
```

예시:

```html
<img src="https://cdn.jsdelivr.net/gh/FlowerBam/yaps-assets@main/emo/hattu_get_idea.webp" alt="하뚜" width="88">
```

## 구성

- `emo/` — 하뚜 이모지 20종 (webp, 176px, 투명 배경)
